# Brand book v1 — ArchMakers

![Brand sheet](brand/brand-sheet.png)

## Name

**ArchMakers** = **Arch**itecture + **Makers**: the place where architects find the makers who build their models (3D print shops, laser-cutting shops and model-making studios).

- Clear for strangers: the name says what the product is.
- Works in English and in Germany ("Arch" and "Maker" are common in both).
- Leaves room to grow beyond 3D printing.

## Logo

An **arch made of horizontal layers**, the way a 3D printer builds a model layer by layer. It's architecture and making in one simple shape. The wordmark is set in Space Grotesk Bold, with "arch" in Ink and "makers" in Burgundy on light backgrounds, or "arch" in Light and "makers" in Rose on dark backgrounds.

## Mascot: Archie

**Archie** is a little arch built from 3D-print layers, with legs, arms and a friendly face. He runs between workshops to find the right maker for you.

| File | Use |
|---|---|
| `brand/archie.svg` / `.png` | Archie waving (light mode): welcome screens, empty states, social posts |
| `brand/archie-search.svg` / `.png` | Archie with a magnifying glass (light mode): search, loading, "finding makers…" |
| `brand/archie-dark.svg` / `.png` | Archie waving, dark mode version |
| `brand/archie-search-dark.svg` / `.png` | Archie searching, dark mode version |

How Archie talks (short, helpful, never silly when someone is stressed):
- "Archie found 5 makers near Munich who can deliver by Friday."
- "No makers match yet. Try a bigger area or a later date."

Archie is for *friendly moments* (onboarding, empty states, loading, social media). He never appears on error messages about payments or complaints.

### Light and dark mode

| | Light mode | Dark mode |
|---|---|---|
| Background | Light `#F5F0EE` | Ink `#241D22` |
| Text | Ink `#241D22` | Light `#F5F0EE` |
| Brand / buttons | Burgundy `#843F55` | Rose `#A0687A` |
| Chips / cards | Blush `#DFD2D1` | `#3A3036` |
| Logo file | `logo-light.svg` | `logo-dark.svg` |
| Archie file | `archie.svg` | `archie-dark.svg` |

Contrast (checked): Burgundy on Light ≈ 6.6:1 and Rose on Ink ≈ 3.8:1, so both are fine for the logo, Archie, buttons and headings. Body text always uses Ink on Light or Light on Ink. Button labels are white.

Starting palette: "Burgundy — Luxury Architecture" (`#241D22`, `#843F55`, `#F5F0EE`, `#DFD2D1`, `#97868B`), with Rose `#A0687A` added for dark mode.

## Tone of voice

**Precise · Helpful · Calm**

We talk like a good colleague in the studio the night before a jury: exact details, no hype, no panic. Archie adds a little warmth, but never jokes when someone is under deadline pressure.

- ✅ **Sounds like us:** "Archie found three makers near Berlin who print 1:200 in white resin and can deliver by Friday."
- ❌ **Not us:** "OMG!!! 🚀 The BEST 3D printing deals EVER — click NOW before they're gone!!!"

Writing rules:
- Lead with the facts architects care about: scale, material, city, delivery date.
- Use short sentences and no exclamation marks.
- Write in German for German users and English everywhere else. Use "Sie" in German.
